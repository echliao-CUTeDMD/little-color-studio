# 小小塗色屋

適合小孩的繁體中文數字填色遊戲。共 89 張原創 SVG 圖畫、1685 個色塊（含 30 張唐詩、24 張二十四孝、20 張童話故事、12 張生肖與 3 張經典圖畫）：十二生肖鼠、牛、虎、兔、龍、蛇、馬、羊、猴、雞、狗、豬各一張，另保留小兔的花園、森林小屋、鯨魚去旅行。十二生肖新增 195 個色塊，可由選圖區切換分類；手機可左右滑動選圖。參考數字填色的玩法，未直接使用提供的圖片。

## 直接試玩

用瀏覽器開啟 `index.html` 即可，不需要安裝或建置。也可在此資料夾執行 `python -m http.server 8000`，開啟 http://localhost:8000。

## 上傳 GitHub Pages

1. 解壓縮 ZIP，在 GitHub 建立一個新的 repository（免費 Pages 可使用 public repository）。
2. 選擇 **Add file → Upload files**，把此資料夾裡的 `index.html`、`style.css`、`app.js`、`zodiac.js`、`fairytales.js`、`filial.js`、`story-audio.js`、`photo.js`、`poems.js`、`README.md`、`.nojekyll` 上傳到 repository 最外層。不要只上傳 ZIP。
3. 按 **Commit changes**。
4. 開啟 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**。
5. Branch 選 **main**，資料夾選 **/(root)**，按 **Save**。
6. 等待 GitHub 部署完成，Pages 設定頁會顯示遊戲網址，一般為 `https://你的帳號.github.io/儲存庫名稱/`。

## 玩法

- 先挑圖，再選顏色，點擊相同數字的區塊填色；選錯顏色會提供提示。
- 自由配色允許使用任意顏色，並可重新替已完成的區塊上色。
- 「找色塊」提示目前顏色尚未填寫的區塊。
- 「上一步」可復原填色與重新開始；重新整理後不保留復原紀錄。
- 進度會使用 localStorage 自動保存在同一瀏覽器，不會跨裝置同步。無痕模式或停用儲存可能無法保留。
- 「儲存作品」下載 1500 × 1260 PNG 圖片，不含數字。
- 支援手機、平板、滑鼠與 Tab / Enter / 空白鍵；音效預設關閉。

## 修改內容

在 `app.js` 的 `COLORS` 修改六種顏色；`SCENES` 定義經典圖畫，`zodiac.js` 定義十二生肖圖畫，`fairytales.js` 定義童話故事，`filial.js` 定義二十四孝圖畫、介紹與區塊答案。每個區塊包含圖形、顏色編號與數字位置。所有素材均在本機檔案內，沒有第三方函式庫、字型、追蹤程式或後端服務。

## 全圖庫語音（89 張）

全部 89 張圖畫各有獨立的繁體中文朗讀內容：30 首唐詩全文與白話解說、24 則二十四孝兒童改寫、20 則傳統童話簡述、12 則生肖動物原創小故事，以及 3 則經典圖畫原創故事。按「聽故事」播放，可邊聽邊填色；提供從頭聽、暫停／繼續、停止、中文聲音選擇及三段語速。暫停後會從目前這一句重讀；切換圖畫或分類會停止舊故事，同一張圖的填色、復原不會中斷故事。故事可展開閱讀。

語音使用瀏覽器的 Web Speech API 與裝置提供的中文合成聲音，優先選擇 zh-TW。這不是預錄 MP3，不需 API 金鑰或後端。聲音、發音與可用性依裝置而異，某些聲音可能需要連網；若沒有中文聲音，可在裝置的語音設定安裝中文語音，或改用提供中文朗讀的瀏覽器。不支援時仍可閱讀文字與填色。需要自行點擊播放，不會自動出聲。

「填色音效」開關僅控制填色提示音；故事另由播放器控制。`story-audio.js` 包含原有 59 篇稿件及共用播放器；唐詩內容位於 `poems.js`。生肖小故事為原創想像，並非生肖排序由來；童話與二十四孝為兒童版改寫，不是原著全文。

驗證：`node story-audio-check.cjs` 檢查逐句播放、語速與聲音設定、暫停續播、停止、切圖取消、過期回呼、不支援與播放錯誤；`node check.cjs` 檢查全部 59 張稿件對應、播放器顯示、逐句播放至結束，以及原有 59 張遊戲功能。未進行真實瀏覽器的聲音試聽，裝置上的音質與發音仍需實際播放確認。


## 上傳照片與數字像素填色

1. 按選圖區的「＋ 上傳照片」。
2. 選擇 JPG、PNG 或 WebP，確認預覽。支援最多 12 MB、2,500 萬像素、長寬比不超過 4：1；HEIC 請先轉成 JPG。
3. 選擇簡單、標準或細緻，分別為最長邊 12、18、24 格；圖畫會依照片比例產生。
4. 按「建立／取代照片填色圖」。程式以照片色彩聚類產生最多六種專屬顏色，並建立可點選的數字像素圖；這不是人物輪廓線稿或 AI 描圖。
5. 在「我的照片」分類填色。可展開完成配色參考圖，使用數字填色、自由配色、提示、復原、自動存檔與下載 PNG。語音為通用創作引導，不會分析照片人物或自動編造照片內容。

保留一張自訂照片填色圖。建立新圖會取代上一張照片圖與進度；選檔、預覽或取消不會取代。原有 89 張圖與進度保留。重新開啟同一瀏覽器後可從「我的照片」找回作品。

照片透過本機瀏覽器 Canvas 處理，不會送往伺服器。只在 localStorage 儲存縮小後的色塊資料、調色盤與填色進度，不儲存原始照片、檔名或原圖中繼資料。儲存遭拒或空間不足時會顯示提示，仍可下載當次作品。原始預覽僅於上傳對話框開啟期間存在，關閉即釋放。

`photo.js` 提供選檔、預覽、色彩聚類、資料驗證及照片畫布建置。`node photo-check.cjs` 檢查尺寸、長寬比、色彩轉換、單色圖片和無效資料；`node check.cjs` 另檢查自訂調色盤、上色、復原、保存、替換與原有作品不受影響。瀏覽器實際檔案挑選、圖片解碼與 PNG 下載尚未實測。
